Schedule

Counted from Day 0

Days 0 to 111 cover the 16 weeks.
Phase 1: Days 0–41. Phase 2: Days 42–76. Phase 3: Days 77–111. The Phase 2 and 3 boundaries are assumed.

Every day: 10-minute mobility routine.
Each 7-day block, starting at Day 0: Lift A, Lift B, off, Lift C, Lift D, then two cardio days.

There are no missed-day counts. Log any day number at any time.

Privacy

The web app URL is stored only on this device. Anyone who has the URL can add rows to your sheet, so keep it private.
