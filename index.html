Program schedule (counted from Day 0)

Days run 0 to 111, which is 16 weeks.
Phase 1: Days 0-41 (Weeks 1-6).
Phase 2: Days 42-76 (Weeks 7-11).
Phase 3: Days 77-111 (Weeks 12-16).

Phase 2 and 3 boundaries are assumed. Tell me if yours differ.

Every 7 days repeat this pattern:
Day 0 of each block: Lift A
Day 1: Lift B
Day 2: off (Phase 3 Zone 2 cardio)
Day 3: Lift C
Day 4: Lift D
Day 5 and Day 6: cardio (Phase 2 run/walk, Phase 3 Zone 2)
Phase 1 has no cardio. There are no missed-day counts, so you can log any day number at any time.

Privacy

The web app URL is stored only in this browser. Anyone who has the URL can add rows to your sheet, so keep it private.
